

\# Design Tokens

|---|---|---|---|

| --bg | #f8fafc | #0b1220 | Main page background |

| --surface | #ffffff | #131c2e | Cards and navigation |

| --text | #0f172a | #e2e8f0 | Main text |

| --muted | #64748b | #94a3b8 | Secondary text |

| --primary | #0ea5e9 | #38bdf8 | Buttons and links |

| --primary-contrast | #ffffff | #06202e | Text on primary backgrounds |

| --border | #e2e8f0 | #243049 | Borders |

| --radius | 0.75rem | 0.75rem | Rounded corners |
