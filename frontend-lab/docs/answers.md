

\# Assignment 1.3 - Short Answers



\## 1. Flexbox vs CSS Grid



Flexbox is a one-dimensional layout system used to arrange elements in a row or column. CSS Grid is a two-dimensional layout system that handles rows and columns together.



Examples:

\- Flexbox: Navigation bars and buttons.

\- Grid: User cards and feature layouts.



\## 2. Utility-First CSS



Advantages:

1\. Faster styling because utility classes are ready to use.

2\. Consistent design without writing many custom CSS rules.



Disadvantages:

1\. HTML and JSX can become difficult to read because of many classes.

2\. Learning utility class names takes time.



\## 3. Design Tokens



Design tokens are reusable variables that store design values such as colours, spacing, fonts and border radius.



They are better than hard-coded colours because they:

\- Keep the design consistent.

\- Make global changes easier.

\- Support light and dark themes.
